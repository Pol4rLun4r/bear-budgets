## Na primeira etapa: avance para definir os valores

Ao abrir o formulário para adicionar ou editar um item, você verá duas opções:

- **À direita — Definir valores do item:** é a ação principal. Clique aqui para seguir para a próxima etapa e preencher os valores.
- **À esquerda — Adicionar item ou Salvar alterações:** essa opção continua disponível para concluir a ação sem avançar, quando os dados informados já forem suficientes. Ela aparece com um destaque mais suave.

## Na etapa de valores: conclua ou volte

Depois de definir os valores, as opções ficam assim:

- **À direita — Adicionar item ou Salvar alterações:** conclui a criação ou a edição do item. O gradiente destaca essa ação principal.
- **À esquerda — Voltar:** retorna à etapa anterior e aparece em violeta claro.

## Como escolher?

Quando quiser continuar o preenchimento ou concluir, procure a ação em destaque à direita. Para voltar e revisar os dados, use **Voltar**, à esquerda.
