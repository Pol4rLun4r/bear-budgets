## Encontre itens pelo código que você tem

Ao adicionar um item a um orçamento, você pode procurar itens já cadastrados usando o campo **Descrição do item**, o **Código interno** ou o **Código do fabricante**. As sugestões são atualizadas conforme você preenche esses campos.

Isso ajuda quando você sabe o código do item, mas não lembra a descrição exata. Por exemplo, mesmo que a descrição digitada seja diferente da que foi salva antes, basta informar o código interno ou o código do fabricante correspondente para encontrar o item e reutilizá-lo.

Quando encontrar o item desejado, selecione a sugestão para preencher os dados já cadastrados.
