## Dados do item em um único texto

Para ter os principais dados de um item reunidos de forma resumida, abra o orçamento, clique com o botão direito sobre a linha do item desejado e escolha **Copiar valores para texto**. As informações serão copiadas em um único texto, pronto para colar onde precisar.

## O que será copiado?

O texto inclui a descrição e o código interno do item, além do valor unitário final calculado. Esse valor considera os cálculos aplicados ao item no orçamento.

Quando a quantidade for maior que uma unidade, o texto também informa a quantidade e o valor total final calculado para todas as unidades. Para uma unidade, essas duas linhas não aparecem.

Por exemplo, para uma unidade:

- **Item:** Porca M8 3 x 4 mm zincada
- **Código do item:** INT-EL-005
- **Valor unitário:** R$ 89,35

Para mais de uma unidade, a cópia inclui também:

- **Quantidade:** 3
- **Valor total:** R$ 268,05

## Previsão de entrega

Quando houver prazo, a previsão é incluída em dias corridos, considerando o embarque e o prazo de entrega. Se o prazo total calculado for zero dias, a linha de previsão não aparece no texto.

O conteúdo copiado fica organizado neste formato:

- `Item: descrição do item`
- `- Código do item: código interno`
- `- Valor unitário: valor final por unidade`
- `- Quantidade: quantidade` *(somente para mais de uma unidade)*
- `- Valor total: valor final de todas as unidades` *(somente para mais de uma unidade)*
- `- Previsão de entrega: prazo em dias corridos` *(somente quando o prazo for maior que zero)*
