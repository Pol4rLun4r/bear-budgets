## Encontre o orçamento que procura

Na tela **Orçamentos**, use a barra de pesquisa para localizar orçamentos pelo **ID** ou pelo conteúdo das **anotações**. Você também pode filtrar a lista pelo status: **Rascunho**, **Concluído**, **Revisar** ou **Declinado**.

## Como pesquisar por ID ou anotações

1. Abra a tela **Orçamentos**.
2. Na barra **Buscar por ID ou anotações**, digite o ID ou uma palavra das anotações.
3. A lista mostra os orçamentos correspondentes. Apague o texto da barra para voltar à lista sem essa pesquisa.

## Como filtrar pelo status

1. Na coluna **Status**, abra o seletor **Status**.
2. Escolha **Rascunho**, **Concluído**, **Revisar** ou **Declinado**.
3. A lista passa a mostrar apenas os orçamentos com o status escolhido. Para remover o filtro, clique no **X** do seletor.

Você pode combinar a pesquisa com o filtro de status para encontrar, por exemplo, orçamentos concluídos que contenham uma anotação específica.
